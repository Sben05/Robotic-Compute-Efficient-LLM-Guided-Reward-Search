## Analysis of Current Reward

| Component | Observation | Issue |
|-----------|-------------|-------|
| **forward_reward** | Grows from 0→8.4 and dominates total reward | Working well, but linear — marginal incentive is flat, no push to exceed current speed |
| **height_reward** | Nearly constant at ~-0.38 throughout training | RL cannot optimize a constant; provides zero gradient signal. Essentially noise. |
| **action_penalty** | Constant ~-0.01, negligible vs. forward_reward (~8) | Too small to influence learning; not contributing |
| **episode_lengths** | Jump from 46→594 then stabilize ~800 | Ant survives and runs, but speed plateaus at ~8 |

**Root causes:**
1. Linear forward reward gives no extra pressure to go faster once the ant achieves a moderate speed.
2. Height penalty is a constant offset (ant stays at ~0.8), so it adds no useful signal.
3. No stability/smoothness term — the ant could potentially oscillate or wobble without penalty.

**Improvements:**
- Add a **quadratic speed bonus** (superlinear) so marginal reward *increases* with speed, pushing the agent beyond the current plateau.
- Replace constant height penalty with a **conditional penalty** that only activates when the ant actually drops (height < threshold).
- Add an **angular velocity penalty** to reward smooth, stable gaits (reduces wobbling at speed).
- Slightly increase action penalty for efficiency.

```python
@torch.jitt.script
def compute_reward(root_states: torch.Tensor, targets: torch.Tensor, actions: torch.Tensor, up_axis_idx: int) -> Tuple[torch.Tensor, Dict[str, torch.Tensor]]:
    torso_position = root_states[:, 0:3]
    velocity = root_states[:, 7:10]
    ang_velocity = root_states[:, 10:13]

    # Unit direction toward target in the horizontal plane
    to_target = targets - torso_position
    to_target = to_target.clone()
    to_target[:, 2] = 0.0
    target_norm = torch.norm(to_target, p=2, dim=-1, keepdim=True)
    target_norm = torch.clamp(target_norm, min=1e-6)
    target_dir = to_target / target_norm

    # Project velocity onto target direction (forward speed)
    forward_vel = torch.sum(velocity * target_dir, dim=-1)

    # Quadratic speed bonus: marginal reward grows with speed, pushing beyond plateau
    speed_temperature = 0.15
    speed_bonus = speed_temperature * forward_vel * forward_vel

    # Conditional height penalty: only activates when ant drops below 0.5
    height = torso_position[:, up_axis_idx]
    height_drop = torch.clamp(0.5 - height, min=0.0)
    height_penalty = 2.0 * height_drop

    # Angular velocity penalty: rewards smooth, stable gait
    ang_vel_sq = torch.sum(ang_velocity * ang_velocity, dim=-1)
    ang_vel_penalty = 0.05 * ang_vel_sq

    # Action regularisation (slightly stronger than before)
    action_sq = torch.sum(actions * actions, dim=-1)
    action_penalty = 0.005 * action_sq

    reward = forward_vel + speed_bonus - height_penalty - ang_vel_penalty - action_penalty

    components: Dict[str, torch.Tensor] = {}
    components["forward_reward"] = forward_vel
    components["speed_bonus"] = speed_bonus
    components["height_penalty"] = -height_penalty
    components["ang_vel_penalty"] = -ang_vel_penalty
    components["action_penalty"] = -action_penalty

    return reward, components
```

**Key changes and why:**

1. **Quadratic speed bonus (`0.15 * v²`):** At the current plateau speed (~8), this adds ~9.6 to the reward. At speed 10 it would add ~15. The marginal gain (derivative = 0.3 v) *increases* with speed, so the agent is always incentivised to go faster — breaking the plateau that a linear reward creates.

2. **Conditional height penalty:** Replaces the constant −0.38 offset. Now it's zero when the ant is upright (no wasted signal) and kicks in hard (2× the drop) only when the ant falls below 0.5. This gives a useful gradient only in the regime that matters.

3. **Angular velocity penalty (0.05 × ‖ω‖²):** New component that penalises wobbling/oscillation. This encourages a smooth, stable running gait, which is especially important at higher speeds where instability would otherwise cap performance.

4. **Action penalty bumped to 0.005:** Still small relative to the speed terms but 5× stronger than before, nudging the policy toward energy-efficient control without distorting the primary objective.
