Looking at the Ant environment, I need to design a reward that encourages the ant to run forward (toward its target) as fast as possible while maintaining stability.

Key available attributes:
- `self.root_states` → torso_position (0:3), velocity (7:10)
- `self.targets` → running direction target
- `self.actions` → for regularization
- `self.up_axis_idx` → which axis is "up"

The reward should:
1. **Reward forward velocity** (projection of velocity onto target direction) — primary objective
2. **Reward maintaining height** — prevents collapsing
3. **Penalize large actions** — encourages efficient control

```python
@torch.jit.script
def compute_reward(root_states: torch.Tensor, targets: torch.Tensor, actions: torch.Tensor, up_axis_idx: int) -> Tuple[torch.Tensor, Dict[str, torch.Tensor]]:
    torso_position = root_states[:, 0:3]
    velocity = root_states[:, 7:10]

    # Compute direction to target in 2D (ignore vertical)
    to_target = targets - torso_position
    to_target = to_target.clone()
    to_target[:, 2] = 0.0

    # Normalize to get unit direction
    target_norm = torch.norm(to_target, p=2, dim=-1, keepdim=True)
    target_norm = torch.clamp(target_norm, min=1e-6)
    target_dir = to_target / target_norm

    # Forward velocity: project velocity onto target direction
    forward_vel = torch.sum(velocity * target_dir, dim=-1)

    # Height reward: keep torso at a reasonable height (~0.8 for ant)
    height = torso_position[:, up_axis_idx]
    height_reward = -torch.abs(height - 0.8)

    # Action penalty: discourage large/jerky movements
    action_penalty = -0.001 * torch.sum(actions * actions, dim=-1)

    # Total reward
    reward = forward_vel + 0.5 * height_reward + action_penalty

    components = {
        "forward_reward": forward_vel,
        "height_reward": height_reward,
        "action_penalty": action_penalty,
    }

    return reward, components
```

**Rationale:**
- **`forward_vel`** is the dominant signal: it's the speed in the target direction, so the agent is directly rewarded for moving faster forward. Linear scaling means there's no ceiling incentive.
- **`height_reward`** (scaled by 0.5) keeps the ant upright and at a standing height, preventing it from "cheating" by sliding on the ground or flipping over.
- **`action_penalty`** (small coefficient 0.001) regularizes the policy toward smooth actions without significantly distorting the primary forward-velocity objective.
- All computations use only `self.`-prefixed environment attributes and are TorchScript-compatible (no Python-only constructs, all tensors on the same device).
