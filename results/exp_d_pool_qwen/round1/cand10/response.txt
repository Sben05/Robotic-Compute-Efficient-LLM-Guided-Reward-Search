Looking at the Ant environment, I need to design a reward that encourages the ant to run forward (toward its target) as fast as possible while staying upright.

Key observations from the environment:
- `root_states[:, 7:10]` gives linear velocity
- `targets` gives the forward direction
- `up_vec[:, 2]` indicates how upright the ant is (1.0 = perfectly upright)
- `actions` can be penalized for efficiency

```python
@torch.jit.script
def compute_reward(
    root_states: torch.Tensor,
    targets: torch.Tensor,
    actions: torch.Tensor,
    up_vec: torch.Tensor
) -> Tuple[torch.Tensor, Dict[str, torch.Tensor]]:
    # Extract torso position and linear velocity
    torso_position = root_states[:, 0:3]
    velocity = root_states[:, 7:10]

    # Compute heading direction in the xz-plane (toward target)
    to_target = targets - torso_position
    to_target[:, 2] = 0.0
    target_norm = torch.norm(to_target, p=2, dim=-1, keepdim=True) + 1e-6
    heading_dir = to_target / target_norm

    # Forward velocity: project linear velocity onto the heading direction
    forward_vel = torch.sum(velocity * heading_dir, dim=-1)

    # Uprightness: z-component of the torso up-vector (1.0 when fully upright)
    upright = up_vec[:, 2]

    # Action magnitude penalty for encouraging efficient movement
    action_magnitude = torch.sum(actions * actions, dim=-1)

    # Temperature / scaling parameters
    forward_temp = 1.0
    upright_temp = 1.0
    action_temp = 0.05

    # Individual reward components
    forward_reward = forward_vel * forward_temp
    upright_reward = upright * upright_temp
    action_reward = -action_magnitude * action_temp

    # Total reward
    reward = forward_reward + upright_reward + action_reward

    rewards = {
        "forward_vel": forward_reward,
        "upright": upright_reward,
        "action_penalty": action_reward,
    }

    return reward, rewards
```

**Design rationale:**

1. **Forward velocity (`forward_vel`)**: The primary reward. It projects the ant's linear velocity onto the direction toward its target (in the xz-plane), directly measuring "how fast is it running forward." Positive values reward forward motion; backward motion is penalized.

2. **Uprightness (`upright`)**: The z-component of `up_vec` is 1.0 when the ant is standing upright and drops toward 0 or negative when it tips/falls. This encourages the ant to stay balanced while running, preventing degenerate solutions where the ant "slides" flat on the ground.

3. **Action penalty (`action_penalty`)**: A quadratic penalty on action magnitudes promotes smooth, energy-efficient locomotion and prevents the policy from producing noisy, high-torque commands. The small coefficient (0.05) keeps it as a regularizer rather than a dominant term.

This combination gives a clear gradient for the policy: maximize speed in the target direction, stay upright, and use efficient control — all essential for "running forward as fast as possible."
