Looking at the Ant environment, I can see the key state variables available:
- `self.root_states`: contains torso position (0:3), rotation (3:7), linear velocity (7:10), angular velocity (10:13)
- `self.targets`: goal positions
- `self.actions`: joint actions
- `self.up_axis_idx`: index of the up axis

For "running forward as fast as possible," the reward should:
1. **Primary**: Reward forward velocity (projection of velocity onto target direction)
2. **Secondary**: Maintain upright posture (torso height)
3. **Penalties**: Angular velocity (stability) and action magnitude (efficiency)

```python
@torch.jit.script
def compute_reward(
    root_states: torch.Tensor,
    targets: torch.Tensor,
    actions: torch.Tensor,
    up_axis_idx: int,
    dt: float,
) -> Tuple[torch.Tensor, Dict[str, torch.Tensor]]:
    torso_position = root_states[:, 0:3]
    velocity = root_states[:, 7:10]
    ang_velocity = root_states[:, 10:13]

    # Direction to target in 2D (ignore z)
    to_target = targets - torso_position
    to_target_2d = torch.stack((to_target[:, 0], to_target[:, 1]), dim=-1)
    to_target_dist = torch.norm(to_target_2d, p=2, dim=-1, keepdim=True) + 1e-6
    to_target_dir_2d = to_target_2d / to_target_dist
    # Extend to 3D with zero z-component for dot product with velocity
    to_target_dir = torch.stack(
        (to_target_dir_2d[:, 0], to_target_dir_2d[:, 1], torch.zeros_like(to_target_dist[:, 0])),
        dim=-1,
    )

    # Forward velocity: how fast the ant moves toward the target
    forward_vel = (velocity * to_target_dir).sum(dim=-1)

    # Temperature parameters
    upright_temp: float = 0.4
    ang_vel_temp: float = 0.3

    # --- Reward components ---

    # 1) Forward velocity reward (primary objective: run as fast as possible)
    forward_vel_reward = forward_vel * 10.0

    # 2) Uprightness reward: keep torso at a reasonable height
    height = torso_position[:, up_axis_idx]
    target_height = 0.8
    upright_reward = torch.exp(-((height - target_height) ** 2) / upright_temp) - 1.0

    # 3) Angular velocity penalty: keep the ant stable
    ang_vel_penalty = -torch.exp(torch.sum(ang_velocity ** 2, dim=-1) / ang_vel_temp) + 1.0

    # 4) Action regularization: discourage excessive joint torques
    action_penalty = -torch.sum(actions ** 2, dim=-1) * 0.01

    # Total reward
    total_reward = forward_vel_reward + upright_reward + ang_vel_penalty + action_penalty

    components: Dict[str, torch.Tensor] = {}
    components["forward_vel"] = forward_vel_reward
    components["upright"] = upright_reward
    components["ang_vel_penalty"] = ang_vel_penalty
    components["action_penalty"] = action_penalty

    return total_reward, components
```

**Key design choices:**

| Component | Rationale |
|-----------|-----------|
| `forward_vel * 10.0` | Dominant term directly optimizes speed toward target; large scale makes it the primary learning signal |
| `exp(-(h-0.8)²/0.4) - 1` | Smooth bounded uprightness bonus (range [-1, 0]) with temperature 0.4 so the ant has ~4cm tolerance around the ideal 80cm height |
| `exp(-‖ω‖²/0.3) − 1` | Smooth bounded penalty for angular velocity, encouraging stable forward running rather than flailing |
| `‖a‖² * 0.01` | Mild L2 action penalty to prevent joint-limit abuse |

The 2D direction to the target ensures the ant is rewarded for *forward* progress regardless of its heading orientation, and avoiding in-place mutations keeps TorchScript-safe.
