```python
@torch.jit.script
def compute_reward(
    root_states: torch.Tensor,
    up_vec: torch.Tensor,
    heading_vec: torch.Tensor,
    actions: torch.Tensor,
    dof_vel: torch.Tensor,
) -> Tuple[torch.Tensor, Dict[str, torch.Tensor]]:
    # Extract linear velocity from root states (indices 7:10)
    velocity = root_states[:, 7:10]
    
    # Forward velocity: project velocity onto the ant's heading direction
    forward_vel = torch.sum(velocity * heading_vec, dim=-1)
    
    # Uprightness: z-component of up vector (1.0 when perfectly upright)
    upright = up_vec[:, 2]
    
    # Height: z-position of torso (avoid dragging on ground)
    torso_height = root_states[:, 2]
    
    # Angular velocity (indices 10:13) for stability penalty
    ang_vel = root_states[:, 10:13]
    ang_vel_penalty = torch.sum(ang_vel * ang_vel, dim=-1)
    
    # Action penalty for efficiency
    action_penalty = torch.sum(actions * actions, dim=-1)
    
    # Temperature / weight parameters
    forward_weight = 1.0
    upright_temperature = 0.5
    height_temperature = 0.1
    action_weight = 0.01
    angvel_weight = 0.01
    
    # Reward: forward velocity (primary goal - run as fast as possible)
    reward_forward = forward_weight * forward_vel
    
    # Reward: uprightness (keep ant standing, use exp transformation)
    upright_error = (1.0 - upright) * (1.0 - upright)
    reward_upright = torch.exp(-upright_temperature * upright_error)
    
    # Reward: maintain reasonable torso height (avoid dragging)
    reward_height = torch.exp(-height_temperature * (torso_height - 0.75) * (torso_height - 0.75)) - 1.0
    
    # Penalty: large actions (encourage smooth, efficient motion)
    reward_action = -action_weight * action_penalty
    
    # Penalty: high angular velocity (encourage stability)
    reward_angvel = -angvel_weight * ang_vel_penalty
    
    total_reward = reward_forward + reward_upright + reward_height + reward_action + reward_angvel
    
    reward_dict = {
        "forward": reward_forward,
        "upright": reward_upright,
        "height": reward_height,
        "action": reward_action,
        "angvel": reward_angvel,
    }
    
    return total_reward, reward_dict
```

**Key design choices:**

1. **Forward velocity (primary reward):** Velocity is projected onto the `heading_vec` (the ant's current facing direction), so the ant is rewarded for moving in the direction it's facing. This is the dominant term with weight 1.0, directly incentivizing running as fast as possible.

2. **Uprightness:** Uses `exp(-temperature * error²)` to give a smooth bonus near 1.0 (upright) and smoothly penalize falling. The `upright_temperature` parameter controls how sharply the penalty increases.

3. **Height maintenance:** A small Gaussian-shaped bonus centered around 0.75 (typical ant torso height) prevents the ant from dragging on the ground while running.

4. **Action penalty:** Small quadratic penalty discourages large, wasteful joint torques while still allowing strong movements needed for speed.

5. **Angular velocity penalty:** Discourages excessive tumbling/rotation, promoting stable locomotion.
