```python
@torch.jit.script
def compute_reward(
    root_states: torch.Tensor,
    targets: torch.Tensor,
    actions: torch.Tensor,
    dof_vel: torch.Tensor,
    heading_vec: torch.Tensor,
    dt: float,
) -> Tuple[torch.Tensor, Dict[str, torch.Tensor]]:
    # Extract kinematic quantities
    torso_position = root_states[:, 0:3]
    velocity = root_states[:, 7:10]

    # --- Temperature / scaling hyper-parameters ---
    up_temp = 2.0          # temperature for upright shaping
    forward_temp = 10.0    # scaling for forward-velocity reward
    action_coeff = 0.01    # action L2 penalty coefficient
    joint_vel_coeff = 0.001  # joint-velocity L2 penalty coefficient

    # 1) Forward-velocity reward: project world velocity onto the ant's heading
    forward_vel = (velocity * heading_vec).sum(dim=-1)
    forward_reward = forward_temp * forward_vel

    # 2) Progress-toward-target reward (horizontal only)
    to_target = targets - torso_position
    to_target = to_target.clone()
    to_target[:, 2] = 0.0
    to_target_norm = torch.norm(to_target, p=2, dim=-1, keepdim=True).clamp(min=1e-6)
    to_target_dir = to_target / to_target_norm
    target_vel = (velocity * to_target_dir).sum(dim=-1)
    target_reward = target_vel

    # 3) Upright / alive reward: keep torso at a reasonable height
    torso_up = torso_position[:, 2]
    # Penalise heights significantly below 0.75 m (typical standing height)
    deficit = torch.relu(0.75 - torso_up)
    alive_reward = torch.exp(-up_temp * deficit) - 1.0  # in [-1, 0]; 0 when upright

    # 4) Regularisation terms
    action_penalty = action_coeff * (actions ** 2).sum(dim=-1)
    joint_vel_penalty = joint_vel_coeff * (dof_vel ** 2).sum(dim=-1)

    # Total reward
    reward = forward_reward + target_reward + alive_reward - action_penalty - joint_vel_penalty

    components = {
        "forward_reward": forward_reward,
        "target_reward": target_reward,
        "alive_reward": alive_reward,
        "action_penalty": action_penalty,
        "joint_vel_penalty": joint_vel_penalty,
    }

    return reward, components
```

### Rationale

| Component | Purpose |
|---|---|
| **forward_reward** | Projects the ant's 3-D velocity onto its heading vector, giving a positive signal only when the ant moves in the direction it faces. Scaled by `forward_temp` to dominate the reward. |
| **target_reward** | Projects velocity onto the horizontal direction toward the spatial target, reinforcing net forward progress even if heading lags. |
| **alive_reward** | A smooth (exp-temperatured) bonus that is 0 when the torso is at or above 0.75 m and approaches −1 when the ant falls. This keeps the ant upright without dominating the learning signal. |
| **action_penalty** | L2 penalty on actions to discourage high-torque, jerky control. |
| **joint_vel_penalty** | L2 penalty on joint velocities for smooth, energy-efficient locomotion. |

All tensor operations stay on the same device as the inputs, and the code uses only TorchScript-compatible constructs (no Python list comprehensions, no type casts, explicit tensor slicing).
